# 🏛️ Lahore Solutions Hub — People-People-For People

A complete civic-tech platform for Lahore's citizens to report issues, propose solutions, vote, and engage with the community.

## ✨ Features

### 🎯 Dashboard
- Real-time statistics (issues, solutions, votes, feedback)
- Interactive charts showing issue distribution
- Top community issues with voting buttons
- Most urgent problems identified

### 📝 Report Issues
- Report specific issues in Lahore
- Categorize by type (Infrastructure, Traffic, Education, etc.)
- Add location details (area/sector)
- Priority rating (1-10)
- Optional solution proposal with your report
- Share your name (optional)

### 💡 Community Solutions
- Browse all proposed solutions
- Filter by category
- Vote for solutions you support
- See who proposed each solution

### 👥 Community Engagement
- **Voting System**: Vote on issues and solutions
- **Feedback**: Share thoughts on any issue
- **Active Members**: Community participation tracking
- **Real-time updates**: Automatic dashboard refresh

### 📊 Data Visualization
- Bar chart: Issues by category
- Pie chart: Solutions distribution
- Live statistics counters
- Priority visualization

## 🚀 How to Run

### Method 1: Direct Open
1. Download all files (`index.html`, `style.css`, `script.js`)
2. Double-click `index.html` to open in browser

### Method 2: VS Code Live Server
1. Install Live Server extension
2. Right-click `index.html` → "Open with Live Server"

### Method 3: Python HTTP Server
```bash
python -m http.server 8000
